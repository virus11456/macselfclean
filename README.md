# MacSweep 1.17

繁體中文原生 Mac 清理與 App 卸載工具。適用於 Apple Silicon、macOS 14 或更新版本。本機編譯、臨時簽署，未經 Apple 公證。

## 從原始碼建立

此儲存庫提供原始碼，不含預先編譯的 App。在 Apple Silicon Mac 安裝 Xcode Command Line Tools 後執行：

```sh
git clone https://github.com/virus11456/macselfclean.git
cd macselfclean
zsh test.sh
zsh build.sh
```

建置完成會產生 `MacSweep.app` 與 `MacSweep.zip`。

## 使用

雙擊 `MacSweep.app`，預設為深度掃描。所有清理項目預設不勾選，查看路徑後再選擇移到垃圾桶。清理前先結束相關 App。工具不會自動清空垃圾桶；搬入垃圾桶不等於已釋放磁碟空間。

深度模式包含近期快取；保守模式僅列出整項超過 7 天未修改的快取，以及超過 30 天未修改的日誌。大小為檔案邏輯大小，不是保證可回收的磁碟空間。

## 掃描範圍

- `~/Library/Caches`、`~/Library/Logs`。
- Claude Application Support 中的 Cache、Code Cache、GPUCache、DawnGraphiteCache、DawnWebGPUCache；不清理對話資料、設定、Cookies、待上傳檔案或工作目錄。
- Chrome 的主要快取在 `~/Library/Caches/Google/Chrome`，另檢查 Application Support 中明確的 GPU 與擴充套件下載快取。
- Chrome 的 Default 與 Profile 數字資料夾，分別列出 Cache、Code Cache、GPUCache 與 Dawn 快取；不把 Cookies、Local Storage 或整個使用者設定檔當成快取。Google 上層資料夾不再整包列出。
- Safari 與 ChatGPT 的標準沙盒 Caches 路徑；另外納入目前這台 Mac 上 ChatGPT／Codex 使用的 Codex 快取及 com.openai.codex/fsCachedData。路徑不存在、無權限或含符號連結時不能保證找到全部快取。
- Google Drive 的已知日誌位置。DriveFS 同步內容與 CloudStorage 離線檔案不列入清理清單；Google Drive 卸載頁僅提供程式本體，不列關聯資料。
- Xcode DerivedData、Archives。封存可能用於發布或除錯，需自行確認。
- iPhone／iPad 本機備份：`~/Library/Application Support/MobileSync/Backup/`。
- 備份頁依中繼資料中的裝置識別值分組，顯示名稱與日期，標記同裝置最新已辨識且記錄為完成的備份。中繼資料的完成狀態不是可還原性驗證；未知身分、未知日期或未記錄完成的項目不會被標記為最新。所有備份仍不預選；手動選到最新備份時會在搬移確認中提醒。
- iPhone／iPad 韌體：`~/Library/iTunes/iPhone Software Updates/`、`iPad Software Updates/` 中的 IPSW。
- `~/Downloads` 及往下兩層一般子資料夾的 DMG、PKG、MPKG、IPSW、ISO。個別列出候選安裝檔，一般文件及父資料夾不會整包刪除。子資料夾需無副檔名、非隱藏、非套件且不含符號連結；已知同步資料夾排除。最多檢查 5,000 個目錄項目，超過上限會記錄未完成。
- `/Applications` 中可辨識的 macOS InstallAssistant 安裝 App。
- `/Library/Updates` 的系統管理資料僅供查看，無法勾選刪除。

單一項目超過 8 秒未完成讀取會略過；整輪掃描上限 90 秒。因逾時、權限或符號連結略過的項目不會計入可清理清單，細節列在紀錄中。掃描工作獨立執行，取消時可停止讀取程序。

## App 卸載

1.3 卸載明細分成程式本體、設定與視窗狀態、快取與日誌、專用文件與帳號資料、歸屬待確認，各組顯示勾選數量。執行前再次檢查預設安裝位置；若新增了同識別碼的另一份 App 或清單讀取失敗，會停止整次搬移。此檢查不涵蓋任意外接磁碟或未列入的自選安裝位置。

列出 `/Applications` 與 `~/Applications` 中的可卸載 App；系統與受保護 App、MacSweep 本身不顯示。其他位置可按「加入其他位置」。

「檢查並卸載」會列出程式本體、識別碼完全相符的 Preferences、Caches、Logs、Application Support、Containers、HTTPStorages、WebKit 與 Saved Application State。這些明確配對的項目會預先勾選，仍須確認才搬移。僅名稱相符的資料列為待確認，預設不勾選。

App 專用資料可能包含文件、帳號與資料庫。共用 Group Containers、鑰匙圈、系統服務、其他使用者帳號及個人在桌面／文件存放的作品，不會自動移除。這不是對所有軟體都能「零殘留」的保證；含驅動或背景服務的產品，應優先用官方卸載程式。

卸載會檢查 App 是否執行中、路徑與項目身分是否變更。程式本體無法移除時，不繼續移除資料；若搬移部分失敗，會明列剩餘路徑。相同識別碼有另一份安裝時，只提供移除該程式本體。不存在跨檔案原子交易，移除前請先結束程式及備份需要的文件。

## 權限

本機實測中，macOS 拒絕讀取裝置備份與部分 Safari／Apple 快取。這不代表它們不存在。裝置備份頁會提示讀取限制；如需讀取，可自行在「系統設定 → 隱私權與安全性 → 完全磁碟存取」加入 MacSweep，然後結束並重開 App。工具不會自行修改權限或要求管理員提權。

Google Drive 在較新 macOS 使用系統 File Provider 管理快取，未同步內容可能位於本機；不應把同步資料直接當成垃圾。參見 [Google 官方說明](https://support.google.com/drive/answer/16631477)。備份位置參見 [Apple 官方說明](https://support.apple.com/en-us/108809)。

## 開發與測試

不必開啟 Xcode 即可使用。若要修改，可用 Xcode 開啟 `Package.swift`。重建執行 `zsh build.sh`，安全與工作程序測試執行 `zsh test.sh`。測試使用自建資料，不清理使用者資料。

`UI_TEST` 為隔離介面測試專用旗標，不在正式建置中啟用。詳細驗證見 `TEST-REPORT.md`。

## 1.4 待確認殘留

在 App 卸載頁切換「待確認殘留」，檢查 Preferences、Caches、Logs 直接子項目中具有反向網域格式識別碼的資料。比對已安裝與手動加入的 App；正式環境另查詢系統登記位置。系統群組、Google Drive、已安裝同廠商的識別碼與符號連結會排除。此頁只提供 Finder 檢查，不提供批次刪除；可能漏掉同廠商的真正殘留，也不能保證其他項目已無用途。

## 1.5 Electron 快取

深度掃描辨識預設安裝位置中帶有 Electron Framework 的 App，依 App 顯示名稱、Bundle 名稱或程式檔名，尋找 Application Support 中相符的資料夾，只列 Cache、Code Cache、GPUCache、DawnGraphiteCache、DawnWebGPUCache。路徑及 App 辨識在搬移前重驗，與既有規則去除重複項目。Google Drive 與系統 App 排除。自訂資料位置、沙盒內位置或特殊快取命名不在本次通用規則涵蓋範圍；全數預設不勾選，清理前需結束相關 App。

## 1.7 同步與備份資料保護

通用快取掃描及刪除前驗證，另外排除 CloudKit、iCloud、com.backup42.desktop、com.pogoplug.Backup、com.dropbox.mbd.external. 前綴，以及 Metadata 上層目錄。這些項目不因位於 Caches 就視為可重建的垃圾。

## 1.8 Chrome 卸載明細

Google Chrome 卸載另外列出 Application Support/Google/Chrome 與 Caches/Google/Chrome。兩者預設不勾選；主要資料包含個人設定檔、書籤、登入狀態與擴充套件。通用快取清理仍只處理指定快取子項目，並不因此清除書籤。Google Drive、Google 上層資料夾與共用更新元件不加入 Chrome 卸載。

## 1.9 卸載明細與變動檢查

每個關聯項目及分組顯示邏輯大小，另顯示目前選取量。重複連結或檔案系統共享區塊可能使邏輯大小不同於可回收空間。

卸載明細記錄子路徑、項目身分、大小、奈秒精度修改與狀態變更時間，以及符號連結目的字串；不讀取連結指向的資料。搬移前整批重新比對，再於逐項搬移前重驗。一般使用中的檔案變動會導致停止；這不是內容雜湊或檔案系統原子快照，不能完全消除最後檢查與搬移間的競態。請先結束相關 App。

單項明細最多 100,000 個項目，於遍歷間檢查 8 秒期限；不完整的明細會略過並顯示原因。期限無法中斷已阻塞的系統檔案呼叫；1.10 已將卸載明細讀取遷移到可中止的獨立程序；實際搬移前重驗仍在原程序執行。

## 1.10 可取消的卸載明細

檢查 App 卸載明細時可按「取消檢查」，整次上限 45 秒。取消或逾時會停止獨立讀取程序，不產生可用的部分卸載計畫，也不移動資料。結果透過僅目前使用者可存取的暫存目錄傳回，結束後清除。此功能不代表已開始的卸載可以中斷或回滾。

## 1.11 可取消的殘留檢查

「待確認殘留」也採用獨立讀取程序，可取消並設有 45 秒上限。候選項目顯示容量；完成、讀取受限、取消與失敗會分別顯示，檢查未完成不會顯示為成功找到零項。這一頁仍為唯讀，僅提供 Finder 檢查。容量為檔案邏輯大小，不代表實際可釋放空間。

## 1.12 共用資料與卸載明細保護

不同 App 的已知關聯路徑若相同，或互為上層／下層目錄，便不列入卸載明細。卸載前重新檢查預設安裝位置，若出現新的共用擁有者，會停止整次操作。名稱比對忽略大小寫，因此可能保守地保留部分資料；這仍不是完整的共用擁有權辨識。

明細必須包含程式本體且沒有重複路徑，所有選取項目都必須存在於明細，否則不移動任何資料。

## 1.13 其他位置 App 的卸載前核對

卸載明細會記錄本次檢查的 App 清單，包含手動加入其他位置的 App。移除關聯資料前，會重新讀取這些位置，確認識別碼及名稱；若已變更、無法讀取或磁碟離線，會停止操作並要求重新整理。可讀取的其他位置 App 也納入重複安裝與共用路徑判斷。只移除程式本體時不要求此關聯資料核對。

識別資料直接重新讀取，不沿用 Bundle 快取。仍不會自動搜尋所有磁碟，1.14 起會保留手動加入的清單，詳見下節。

## 1.14 記住其他位置

手動加入的 App 位置與識別資料會儲存在本機偏好設定中，重新整理與重開程式後會重新核對。讀不到或身分改變的記錄會保留並提示，仍納入關聯資料的卸載前核對。殘留檢查也會參考已記錄的 App。

「其他位置記錄」可忘記個別位置或清除全部記錄，只移除 MacSweep 記錄，不刪除 App 或文件。忘記位置後，該 App 不再透過此記錄受到共用資料保護；需要時可重新加入。位置資料毀損會回報錯誤並停止卸載明細檢查，重設記錄後再加入。尚未使用可追蹤 App 搬移的書籤，移動或重新命名後需重新加入。

## 1.15 卸載失敗即停止

卸載仍先移動程式本體，再逐項移動所選關聯資料。任何一項重新核對或搬移失敗，就會停止後續搬移；結果列出已移動與未移動的路徑。已移到垃圾桶的項目不會自動回復，需到垃圾桶手動還原。本次變更適用 App 卸載，不改變一般清理頁的逐項處理方式。

## 1.16 可複製的卸載紀錄

完成或停止卸載後，可按「上次卸載紀錄」查看 App 名稱、操作時間、停止原因，以及已移動與未移動路徑，並複製成文字。未移動清單包含失敗及尚未處理的項目，不將兩者誤報為全部失敗。紀錄描述操作當時結果，不追蹤後續檔案變化，也不提供自動還原。

目前只保留 App 管理頁這次存續期間的最後一筆，重新整理清單不會清除，但關閉 App 或重建該頁可能失去紀錄；需要留存請先複製。

## 1.17 本機保存最後一筆卸載紀錄

1.16 的僅記憶體限制已更新：現在使用本機偏好設定保存最後一筆紀錄，App 重開後可讀取。紀錄含 App 名稱、時間、路徑與錯誤，下一次卸載會取代；可使用「清除卸載紀錄」移除保存的紀錄，不會刪除 App、文件或垃圾桶內容。

保存失敗時仍可複製記憶體中的本次結果，並會提示重開後可能讀到舊紀錄。超過 4 MB 的紀錄不保存。這仍不是完整操作歷史或當機復原日誌，操作中途異常退出時不保證留下本次結果。
